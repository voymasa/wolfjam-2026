## Core Concept
Talk to cows to get them to light up your path (make it visible).

## Core Features
Animated Cows

Cows that Talk

Paths that light up the way when you talk with the cows

## Core Loop
Talk to a cow, follow the new path to the next cow, .... , profit!

## How to Use
Run the scene in the editor. Select one of the Cows. Open the context menu for the NPC Speech script in the Inspector. Click 'Speak Cow'
